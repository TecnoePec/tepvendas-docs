# TepVendas Docs

Documentacao tecnica do TepVendas - Sistema de Gestao de Vendas e Pedidos.

**Site:** https://tecnoepec.github.io/tepvendas-docs/

## Desenvolvimento local

```bash
pip install -r requirements.txt
mkdocs serve
# Acesse http://localhost:8000
```

## Deploy

Push para `main` faz deploy automatico para GitHub Pages via GitHub Actions.
